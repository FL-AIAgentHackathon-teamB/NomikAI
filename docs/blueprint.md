# **App Name**: Nomini

## Core Features:

- Calorie Input: Allow users to input remaining or target calorie intake for the day.
- Image Analysis: Upload meal photos for AI-powered food name identification and calorie estimation, using Gemini Pro as a tool.
- AI Advice Generation: Generate personalized advice based on remaining calories (e.g., "Okay to eat" or "Eat in moderation") using Gemini Pro as a tool.
- Result Display: Clearly display analysis results and AI-generated advice.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to evoke a sense of health and energy.
- Background color: Light blue (#E5F5FB) for a clean, calming feel.
- Accent color: Yellow-orange (#F2A900) to highlight key information and calls to action.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and readable interface.
- Note: currently only Google Fonts are supported.
- Use simple, clear icons to represent different food categories and workout types.
- Mobile-first design: prioritize a single-handed operation for use at the gym or during meals.
- Subtle animations and transitions to provide feedback during calorie input and analysis.
